# scada

#### Description
aiot物联网SCADA系统，纯Java B/S架构，无环境依赖，资源占用低，一键秒级安装。快速集成传感器、控制器、视频、机械手。支持环境监控、设备联动、协议转换、图像识别标注，数据可视化等模块。可做轨道轮式机器人系统，工业控制及组态，广泛应用于工业、农业、教育、家庭...
